Introduccion

Bienvenido a la documentacion tecnica de WeatherAPI, una interfaz diseñada para la consulta de datos meteorológicos.

Para obtener mas informacion general sobre los servicios, puedes consultar la documentación oficial de WeatherAPI.

Autenticacion

El acceso a los endpoints requiere el uso de una clave de API valida enviada en las cabeceras de la peticion.

Te recomendamos revisar detalladamente la política de seguridad de WeatherAPI antes de integrar el servicio en producción.

Endpoint de usuarios

Gestiona los perfiles y permisos de los desarrolladores registrados en la plataforma.

  • GET /v1/users: Lista los usuarios activos.
  • POST /v1/users: Da de alta un nuevo usuario.

Endpoint de ciudades

Permite consultar informacion meteorologica detallada por localidad geografica.

  • GET /v1/cities/{id}: Devuelve el clima actual y previsiones de una ciudad.
